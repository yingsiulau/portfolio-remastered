# /3D models

Drop the exported glTF binary here as `alley-akihabara.glb` — that's the
path [`ThreeD.jsx`](../../src/pages/ThreeD.jsx) loads via `ModelViewer`.

Source scan: https://poly.cam/capture/25E9E812-DE39-4101-BE33-D2243E08F849
("Some alley in Akihabara" by Whoismo on Polycam)

To export: open the capture on Polycam while logged in → **Export** →
choose **glTF (.glb)**. Until the file exists here, the `/3d` page shows
a placeholder wireframe instead.
